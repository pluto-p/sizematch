🎯 RunwAI Integration Guide

Quick Start (30 seconds)

Add this single line to your website's HTML, preferably before the closing </body> tag:

<script src="https://runwai.com/embed-widget.js"></script>

That's it! RunwAI will automatically:

  • ✅ Detect size selectors on your product pages
  • ✅ Add the "Find My Size with RunwAI" button
  • ✅ Handle all the sizing logic
  • ✅ Work on mobile and desktop

Advanced Integration

Custom Button Placement

If you want to control exactly where the button appears:

<div id="runwai-button-container"></div>
<script>
  window.RunwAIConfig = {
    container: '#runwai-button-container',
    buttonText: 'Find My Perfect Size'
  };
</script>
<script src="https://runwai.com/embed-widget.js"></script>

E-commerce Platform Plugins

  • Shopify: Install our app from the Shopify App Store
  • WooCommerce: Download our WordPress plugin
  • Magento: Use our Magento extension
  • BigCommerce: Install via the BigCommerce marketplace

Testing

After integration, visit any product page and look for the "Find My Size with RunwAI" button. Click it to test the sizing experience.
